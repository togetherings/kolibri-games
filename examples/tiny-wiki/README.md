# Tiny wiki

About 20 short, linked articles in the same shape as a Wikipedia ZIM file, for
tests and for trying Wiki BLAZE in the preview server without a real Wikipedia
file:

    kolibri-games-preview games --wikipedia examples/tiny-wiki

`_redirects.json` lists redirects ("Cats" goes to "Cat"). "Unicorn" is linked
from "Egg" but has no article, like a red link on Wikipedia.
